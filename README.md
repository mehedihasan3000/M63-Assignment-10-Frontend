# 🩸 Blood Connect

A modern blood donation management platform that connects blood donors with recipients through a secure, role-based system. Users can create and manage blood donation requests, search for donors, and collaborate through dedicated dashboards for Donors, Volunteers, and Admins.

## 🌐 Live Links

* **Live Site:** https://blood-connect-client.vercel.app/
* **Server API:** https://blood-connect-server-one.vercel.app/
* **Client Repository:** https://github.com/mehedihasan3000/M63-Assignment-10-Frontend
* **Server Repository:** https://github.com/mehedihasan3000/M63-Assignment-10-Backend

---

## 🚀 Features

* Secure authentication with **BetterAuth**
* Role-based access control (Admin, Volunteer, Donor)
* User registration and profile management
* Create, update, delete, and manage blood donation requests
* Search donors by blood group, district, and upazila
* Donation request status tracking (Pending → In Progress → Done/Canceled)
* Admin dashboard for user and donation request management
* Volunteer dashboard with request status management
* Responsive dashboard and user interface
* Protected routes and secure API integration

---

## 👥 User Roles

### 🩸 Donor

* Manage personal profile
* Create and manage donation requests
* Respond to donation requests
* Search blood donors

### 🤝 Volunteer

* View all donation requests
* Update donation request status

### 🌐 Admin

* Manage all users
* Block / Unblock users
* Assign Admin or Volunteer roles
* Manage all donation requests
* View platform statistics

## 📦 Installation

### Clone the repositories

```bash
git clone https://github.com/mehedihasan3000/M63-Assignment-10-Frontend.git
git clone https://github.com/mehedihasan3000/M63-Assignment-10-Backend.git
```

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env` file for the client and a `.env` file for the server, then add the required environment variables.

### Run the project

Client:

```bash
npm run dev
```

Server:

```bash
npm start
```
